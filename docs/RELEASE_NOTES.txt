Chamo 0.1.0 — 首个版本
2026-10-21

Chamo（卡莫）是一个本地文件转换工具：像变色龙换颜色一样，给文件换格式。全部在本机处理，原件始终保留。

支持的转换
• PDF 转图片：PNG/JPEG，页范围、DPI；大 PDF 显示逐页进度，取消或中断后已完成的页直接复用。
• PDF 拆分：同时按页数和实际文件大小限制拆分，无法验证内容完整的结构列为异常。
• PDF 合并：按列表顺序合并，可拖动调整顺序；含复杂表单、附件或交互结构的 PDF 拒绝合并。
• PDF 压缩：无损清理（没有收益时如实说明），或主动选择的有损重采样；加密和带数字签名的 PDF 拒绝处理。
• Office 转 PDF / 图片：Word、PPT、Excel、WPS（.wps/.et/.dps）及模板、启用宏的文件（不会执行宏），使用内置 LibreOffice 本地渲染。
• 图片合成 PDF：按顺序合成，支持原尺寸或 A4/A3/Letter 加边距，不裁剪。
• 图片格式转换与压缩：PNG/JPEG/WebP/TIFF/BMP 输出，HEIC、AVIF 输入；PNG 无损优化；降低质量或尺寸需要主动选择。
• RAG 预处理：保持目录结构、保留 Word/PPT 原格式、排除音视频，逐项校验后生成上传清单与批次。

界面与效率
• “开始”页：拖入任意文件，按可处理的数量推荐转换；也可以把文件直接拖到侧栏的工具上。
• ⌘K 搜索工具，⌘0–⌘9 切换工具，⌘/ 查看全部快捷键；Dock 右键菜单；Finder 右键“服务 → 用 Chamo 处理”。
• 常用预设、文件缩略图、按列排序、按状态筛选、⌘Z 撤销移除、空格快速查看、图片前后对比。
• 简洁命名（如“讲义/讲义_001.png”），同名时自动加“ (2)”，绝不覆盖；可保存到固定文件夹或原文件旁。
• 失败的文件给出中文原因和修复建议，可一键“重试异常项”；历史记录按日期分组，可搜索。
• 检查更新：手动检查或主动开启自动检查（默认关闭，关闭时不联网）。
• 小文件按批处理，上千个小图片数秒完成。
• 设置窗口可选择界面语言：简体中文、English 或跟随系统。目前只覆盖设置窗口本身，主窗口、菜单和转换结果里的提示仍为中文。

Windows 与 Linux
• Windows 便携版（chamo-cli_版本号_windows-x64.zip）与 Debian/Ubuntu 安装包（amd64、arm64）：命令行加本机浏览器界面（chamo ui，只在 127.0.0.1 提供，带随机令牌）。与 macOS 应用使用同一个引擎、同一套规则。

修复
• 取消 PDF 转图片时，正在编码的页面会先停下再返回，输出目录不再残留暂存页面。

已知限制
• macOS 版需要 Apple Silicon、macOS 15 或更新版本；采用 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。
• Windows 便携包未签名；Linux 与 Windows 上的 Office 转换需要系统已安装 LibreOffice。
• 取消时正在处理的那个文件，状态显示为“失败”，而不是“已取消”（原件和输出目录都不受影响），会在后续版本修正。
• HEIC 解码只在 macOS 上可用。
• OCR、PDF 转可编辑 Office、长图拼接、压缩包解包、音视频处理属于后续规划。
