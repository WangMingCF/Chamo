Chamo 0.1.0 使用说明

Chamo（卡莫）是一个本地文件转换工具：像变色龙换颜色一样，给文件换格式。所有转换都在你的电脑上完成，文件不上传，原件始终保留。


一、安装

macOS（Apple Silicon，macOS 15 或更新）
打开 DMG，把“Chamo.app”拖入“应用程序”，双击启动。Python、PDF/图片引擎和 LibreOffice 都已内置，不需要另装任何东西。
本版本尚未经过 Apple 公证。如果系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开这个应用；不要关闭系统的全局安全保护。

Windows 10/11 x64
下载 chamo-cli_版本号_windows-x64.zip，解压后运行“chamo.cmd ui”打开本机界面。安装包未签名，SmartScreen 可能提示一次。

Debian/Ubuntu（x86_64、arm64）
安装 deb 后运行“chamo ui”。Office 转换需要系统已安装 LibreOffice（deb 中声明为推荐依赖）；PDF 与图片转换不需要。

Windows 与 Linux 的界面是一个浏览器页面，只在本机（127.0.0.1）提供，地址带随机令牌，别的网页打不开它。这个地址不要贴给别人或发到聊天工具里（它会进入浏览器历史）。点“退出”会先取消正在进行的转换再关闭；直接关掉浏览器标签页不会停止转换，要停止请点“退出”或在终端按 Ctrl-C。


二、快速开始

1. 把文件或文件夹拖到“开始”页，Chamo 会按可处理的文件数量推荐转换，点一个推荐进入对应工具。也可以直接从侧栏选工具，或把文件拖到侧栏的工具上。
2. 在右侧调整设置。常用预设可以一键套用；页面范围支持“1-5,8,12-20”这样的写法，并会实时检查。
3. 在底部确认保存位置（固定文件夹或“原文件旁”），点“开始转换”（⌘↩）。
4. 运行中可以暂停、继续或取消。完成后点“在 Finder 中显示”，会直接选中本次的结果。

Windows/Linux 的页面只有一条流程：选文件或文件夹 → 选转换类型和参数 → 选输出目录 → 开始转换 → 看进度（可取消）→ 打开结果。


三、各类转换

PDF 转图片
导出 PNG 或 JPEG，可选页范围和 DPI。这是静态导出：不保留文字层、链接、附件和交互。单页最多 6400 万像素，超出时会报错并建议降低分辨率，不会自动降低清晰度。
• 大文件自动分片：扫描件这类“整页都是图片”的 PDF，会把页范围分给多个进程并行渲染。是否分片由成本模型判断：只有预计端到端至少快 1.10 倍才分片，文字型 PDF 不分片，每片至少 16 页。分片只影响速度，不影响结果：分片与不分片的文件名、页数和每个文件的内容完全相同。繁忙的电脑或只有 2 核的机器上分片可能略慢，可以用命令行参数 --shard off 关闭。
• 断点续跑：取消、崩溃或断电后重新提交同一次转换，已渲染完成的页直接复用，不再整份重渲染。缓存放在系统应用数据目录，默认保留 7 天、整机上限 2 GiB，按最近使用淘汰；过期或被删只会让下一次重新渲染。来源文件、格式、DPI（JPEG 还包括质量）任一变化都会从头渲染。设置环境变量 CHAMO_PAGE_CACHE=0 可以关闭。

PDF 拆分与合并
• 拆分同时限制每份的页数和实际文件大小；无法验证内容完整保留的结构会列为异常。
• 合并按列表顺序进行，可以拖动行、用 ⌥⌘↑/↓ 调整，或按列标题排序。含表单、附件、结构标签或交互批注的 PDF 会被拒绝合并，原件保留。

PDF 压缩（两种方式明确分开）
• 无损清理（默认）：只重写 PDF 内部结构，页面内容不变；发布前会重新打开成品，核对页数、抽样页的文字和渲染结果。如果没有变小，会给你一份与原件完全相同的副本，并在报告中写明“没有收益”。已经是最优结构的 PDF 通常没有收益。
• 有损重采样（需主动选择）：每一页按所选分辨率（默认 150 DPI）渲染成 JPEG（质量默认 75）后重建 PDF；文字层、链接和表单不再保留。如果成品没有比原件小，就不生成成品，说明原因并保留原件。
• 加密 PDF 和含数字签名的 PDF（压缩会使签名失效）两种方式都拒绝处理；有损方式遇到页面旋转或裁切框与页面尺寸不一致的 PDF 也会拒绝，并建议改用无损方式。带 /UserUnit 的大图纸会保留原打印尺寸。

Office 转 PDF / 图片
支持 Word、PPT、Excel、WPS 文档（.wps/.et/.dps）及模板、启用宏的文件（不会执行宏）。使用 LibreOffice 本地渲染，缺失的字体会被替代，复杂版式请检查。动画、交互和演讲者备注不会进入 PDF 或图片。

图片合成 PDF
按列表顺序合成一个 PDF，可选原图尺寸或 A4/A3/Letter 加边距，图片等比缩放、不裁剪。多帧图片（如 GIF 动图）会列为异常。

图片格式转换与压缩
• 输出 PNG、JPEG、WebP、TIFF、BMP；支持读取 HEIC（仅 macOS）和 AVIF。
• 无损优化只支持静态 PNG，并逐像素校验；JPEG 输入在无损方式下会被明确拒绝，不会偷偷有损。
• 降低质量或尺寸需要主动选择：macOS 可选 JPEG 或 WebP，Windows/Linux 页面固定输出 JPEG；可设置质量（1–100）和最长边（0 表示不限制）。给 PNG 设质量会直接报错，而不是静默忽略。
• JPEG 不支持透明，透明区域会填充为白色。多帧图片不会被静默丢帧。

RAG 预处理
保持输入根目录的相对结构和原格式，Word/PPT 不会转成 PDF。PDF 默认按每份最多 100 页且不超过 100,000,000 字节拆分（MB 按十进制计）。音视频（包括 .ts）自动排除。只有逐项校验通过的文件才会进入 upload-manifest.jsonl；异常文件保留原件并写入报告。


四、输出与命名

• 简洁命名（默认）：多页结果放在以原文件命名的文件夹，例如“讲义/讲义_001.png”；单个结果保持原名，例如“照片.jpg”“讲义_合并.pdf”。遇到同名文件自动改为“名称 (2)”，绝不覆盖已有文件。
• 带任务标识：保留原扩展名并附加 8 位任务标识，便于追溯。可以在右侧或设置中切换。
• 保存位置：固定文件夹，或“原文件旁”（在原文件所在目录新建“Chamo输出”）。来源分散在多个目录时，会改用固定文件夹并提示。
• 输出目录里只有成品。一次转换多个文件、且每个文件各自产出成品时，会多一个“清单.json”，列明每个来源产出了什么、状态和失败原因；已有同名文件时另建“清单 (2).json”。单个文件、多图合成一个 PDF、被取消的批量都不生成清单。
• 运行记录（任务、哈希、异常、报告、续跑凭据）是内部数据，保存在系统应用数据目录（macOS 为“~/Library/Application Support/Chamo”），不放进输出目录。每个输出目录只保留最近 20 次运行和 500 条续跑凭据，30 天未使用的记录会自动清理。
• 重新转换同一批文件时，已完成且未被改动的成品会被复用。成品全部删掉后可以重新生成；只删了一部分或内容被改过时会拒绝，以免覆盖你的修改。


五、效率技巧（macOS）

• ⌘K 搜索工具和操作；⌘0 回到“开始”；⌘1–⌘9 切换工具；⌘/ 查看全部快捷键。
• 空格或 ⌘Y 快速查看；Delete 从列表移除（不会删除文件），⌘Z 撤销。
• 图片结果的预览可以切换到“对比”，拖动分隔线比较画质。
• 转换完成的行可以直接拖到 Finder、邮件或聊天应用。
• 失败的文件：选中后在右侧查看原因和修复建议。“重试异常项”只会真正重跑失败或未完成的文件，已完成的成品直接复用。
• 在 Finder 中选中文件，右键“服务 → 用 Chamo 处理”可以直接送入应用（系统可能需要片刻才会显示这个服务）。
• 右键程序坞图标可以直接打开工具或添加文件。


六、命令行（可选）

需要在脚本里批量处理时，可以使用随应用发布的命令行工具 chamo，它与界面使用同一套引擎和校验规则。
macOS 路径：Chamo.app/Contents/Resources/bin/chamo，可以链接到 PATH：
  ln -s "/Applications/Chamo.app/Contents/Resources/bin/chamo" /usr/local/bin/chamo

示例：
  chamo 讲义.pdf -o 输出 -t pdf-images --dpi 150 --range 1-10
  chamo 资料/ -o 上传 -t rag --pdf-pages 100
  chamo 照片/ -o 结果 -t image-convert --format webp --lossy
  chamo 照片/ -o 结果 -t image-compress --lossy --quality 80 --max-edge 2000
  chamo 讲义.pdf -o 结果 -t pdf-compress
  chamo 扫描件.pdf -o 结果 -t pdf-compress --lossy --dpi 150 --quality 75
  chamo ui                      打开本机浏览器界面（Windows 为 chamo.cmd ui）
  chamo --help                  查看全部参数

可用转换类型：pdf-images、images-pdf、pdf-split、pdf-merge、pdf-compress、office-pdf、office-images、image-convert、image-compress、rag。
pdf-compress 默认无损；--dpi 和 --quality 只用于 --lossy，无损方式带这两个参数会在开始前报错。
退出码：0 成功；1 有文件失败但其余完成；2 参数错误；3 已取消；4 内部错误。--json 输出原始事件流（带协议版本号）。Ctrl-C 会连同后台转换一起停止。


七、常见问题

打开时提示“无法验证开发者”
本版本尚未经过 Apple 公证。请在“系统设置 → 隐私与安全性”中允许打开 Chamo。

转换停在暂停状态
输出盘可用空间低于 2 GB 时会自动暂停，腾出空间后点“继续”。单个文件 20 分钟没有任何进展才会被终止（暂停时间不计）。

Office 转换失败
Windows 与 Linux 需要系统已安装 LibreOffice；macOS 版已内置。文件加密或损坏时，请先用原软件另存一份再试。

检查更新
应用菜单“Chamo → 检查更新…”（也可在设置或 ⌘K 中找到）会向 GitHub 查询最新的正式版本。“启动时自动检查更新”默认关闭，关闭时应用不会联网。

反馈问题
侧栏“反馈与建议”或帮助菜单会打开反馈表单，填写后在浏览器中检查内容，再提交到 GitHub Issues。默认不附带环境信息，也不会自动收集文件、文件名、路径、日志或账户信息。

暂不支持
OCR、PDF 转可编辑 Office、长图拼接、压缩包解包、音视频处理属于后续规划。
