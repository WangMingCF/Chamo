# 本轮任务（第 {{ROUND_ID}} 轮）

这是一次有时限的运行，做完一轮就退出，循环驱动会再启动下一轮。

1. 核实现状：git fetch；看 open PR（尤其自己的 PR 上的评审评论和 CI 结果）、Release、CI；看工作区有没有未完成的改动。
2. 优先处理已有 PR：评审要求修改就修；检查全绿且评审通过就合并并完成该版本的发布与记账。
3. 否则按 docs/ITERATION_PLAN.md 第 2 节的闭环推进下一个版本或子项；一轮做不完就把进度留在分支和 PR 说明里，下一轮接着做。
4. 结束前把本轮报告写到 {{ROUND_REPORT}}（Markdown，5–10 行，会原样发到公开的状态 Issue）：
   - 本轮做了什么（PR/Release 链接）
   - 关键数字（改前 → 改后，含重复次数与波动）
   - 新发现的竞品差距或否定结论
   - 下一轮要做什么
   - 阻塞与需要维护者决定的事
   报告里不要出现任何路径以外的服务器信息、令牌、密钥或个人身份信息。没有写报告就算本轮失败。
